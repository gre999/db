# 期末報告主軸(草案,第 13 週定案)

## 主旨

**機器學習能改善預測指標,但在扣除實際成本後,無法在現有樣本下顯著改善 QQQ 短期策略的
績效。**

這句話裡三個限定詞都是刻意的,不是隨口加的緩衝:「能改善預測指標」——階段二、四、五都有
模型在 QLIKE/AUC 這類純預測指標上贏過基準,不是全面沒有訊號;「扣除實際成本後」——策略層
的差異顯著性檢定(block bootstrap)才是真正的門檻,純預測指標的優勢常常撐不到這一層(階段
四證據階梯的核心發現);「現有樣本下」——檢定力分析(週10、週13)量化了這不是「還沒找到對
的模型」,是現有 OOS 樣本量在統計上本來就偵測不到這個量級的效果,跟模型好壞無關。

## 章節結構與各階段支撐段落

### 階段一(週1–2):資料品質與特徵工程 —— 不寫獨立支撐段落

基礎設施,沒有自己的預測或策略主張,不對主旨提供直接證據,只是後續全部階段的前提(資料
清理、無前視偏誤的特徵矩陣)。

### 階段二(週3–5):波動率預測與部位管理

HAR+殘差XGB 對 HAR 的 QLIKE 顯著更低(Diebold-Mariano 檢定,見 `results_summary.json`),
預測指標層面確實改善;但轉成波動目標部位規模的策略後,HAR+殘差XGB 對 HAR 的夏普差只有
-0.0026(p=0.9173),對 20 日歷史波動的夏普差 -0.0161(p=0.8517),兩個都不顯著——**預測
準了,策略沒有跟著顯著變好**,是全篇主旨第一次出現的具體例子。本階段另外修正了 20 日歷史
波動部位權重的前視偏誤(見修正紀錄附錄),修正前後的夏普從 1.4715 掉到 1.1568,原本「hist20
顯著贏」的框架修正後不成立。

### 階段三(週6–7):市場狀態標籤

兩篇策略論文複現通過(見下「附帶結果」),市場狀態(HMM/KMeans)本身可以被模型外驗證確認
(預測型狀態分組的已實現波動差異,Newey-West HAC t值 9.9/12.2,p≈0,狀態標籤本身不是雜訊),
但拿這些狀態去篩選 ORB/VWAP 交易日,18 個「狀態 vs 全樣本」比較裡 0 個顯著,HMM 篩選後的
夏普甚至比不篩選更差(ORB: 0.20 vs 0.35;VWAP: 0.89 vs 1.01)——**狀態標籤本身有效,不代表
拿它篩選交易日有效**,是主旨的第二個例子,也是階段四要換一個更直接角度(用交易日本身的
開盤特徵,而不是市場狀態分類)的直接動機。

### 階段四(週8–10):交易日篩選

logistic 篩選 ORB 字面上通過原始三項成功標準(篩選後夏普 0.707 對不篩選 0.517),但補做
block bootstrap 後 p=0.485,不顯著;五個模型(logistic、隨機森林、XGBoost 深度2/3、Huber
迴歸)沒有一個四項嚴格標準(含 block bootstrap p<0.05)全過。檢定力分析首次把這個現象量化:
最小可偵測夏普差約 0.69–0.70,遠大於實際觀察到的 0.17–0.22——**不是模型不夠好,是現有
~8.7年 OOS 樣本量本來就測不到這個量級的效果**,這是全篇對主旨「現有樣本下」這個限定詞
最直接的證據來源。

### 階段五(週11–13):深度學習(CNN)

放棄手工特徵、直接餵分鐘序列給 CNN,結果 CNN 顯著比手工特徵 logistic 差(AUC 差 -0.055,
p=0.001,效果量本身就大到可偵測,不是檢定力問題),三項增量資訊檢查(Spearman、R²、堆疊)
一致確認 CNN 沒有超出手工特徵的資訊。任務B(開盤後15/30分鐘預測剩餘時段方向)AUC層與策略層
一致確認沒有可用訊號。**這是主旨最強的一次反例確認**:換一個完全不同、理論上表達力更強的
模型架構,不但沒有改善,反而更差——說明階段四的負面結論不是「手工特徵這條路選錯了」,而是
這個決策問題(用日內早期資訊預測當天剩餘走勢/進場成敗)本身在現有樣本量下的訊噪比就是這樣。

## 方法論章節

1. **事先寫定設定**:每週 config/weekNN_*.toml 在看任何績效數字之前寫定,結果不論好壞
   照實報告,不因結果不理想就放寬標準或悄悄多跑幾次換更好看的數字(貫穿全部13週,最直接
   的例子是第8週的三項標準字面達成但補檢查後推翻)。
2. **巢狀 walk-forward**:訓練段內再切配適/驗證段,測試段完全不參與配適或選門檻,選定的
   模型與門檻原封不動套用到測試段、不重新配適(第8週起貫穿到第13週)。
3. **截斷與篡改測試**:第11/12週CNN序列特徵的洩漏檢查——truncation test(確認特徵在
   截止時間點之後被截斷不影響预测)+ mutation test(篡改截止時間點之後的資料,同日晚期
   與所有更晚交易日兩種篡改都測,因為成交量通道會讀取更早的交易日歷史)。
4. **隨機篩選基準與 block bootstrap 雙層檢定**:排序層(隨機篩選基準的經驗p值,模型排序
   的訊號選中的日子跟隨機選同樣天數比有沒有差)vs 策略層(block bootstrap,篩選前後夏普差
   本身站不站得住腳)——階段四證據階梯(`stage4_chapter.md`第四節)的核心方法論貢獻,兩層
   經常不一致,策略層比排序層嚴格得多。
5. **檢定力分析**:第10週引入(Sharpe差的最小可偵測效果量),第13週擴大到AUC差、並補算到
   階段二、三(標註「事後補算,僅供判讀,不改變原結論」)。

## 限制與未來工作彙總

不重寫每階段章節已經寫過的限制,只做跨階段層級的彙整:

- **樣本量是貫穿全專案的根本限制**,不是任何單一階段的執行問題——第10週(Sharpe)、
  第13週(AUC)兩次檢定力分析從不同指標得到一致結論。
- **2022年做空訊號排序顛倒**(階段四附帶發現):三個模型(logistic、隨機森林、XGBoost)
  在2022年一致犯同一方向的錯,只能算一個假說,不是三次獨立驗證(都用同一組特徵、高度重疊
  的訓練窗)。列為未來工作:調查具體機制。
- **LSTM/更長記憶架構**(階段五):列為未來工作,前提是未來有明顯更長的分鐘級歷史資料
  可用才成立,不是現在的下一步——理由見`stage5_chapter.md`第六節。
- **探索性結果一律標注不列入成功判斷**:階段四的兩特徵logistic模型、階段五的CNN變體等,
  任何看完結果後才挑選的組合都打上探索性折扣。
