# 摘要

本專題用 14 週時間,系統性檢驗機器學習能否改善 QQQ(納斯達克100指數ETF)的短期交易策略。研究涵蓋四個依序遞進的方法階段:波動率預測與部位管理(階段二)、市場狀態標籤(階段三)、交易日篩選(階段四)、深度學習(階段五)。每個階段都遵循同一套方法論紀律——設定在看任何結果之前寫定、結果不論好壞照實報告、任何事後修正都留下紀錄。

主要發現:**機器學習能改善預測指標,但在扣除實際成本後,無法在現有樣本下顯著改善 QQQ 短期策略的績效。** 四個階段裡,預測層(QLIKE、AUC、外部驗證檢定)經常出現統計上站得住腳的訊號或改善,但策略層(交易策略本身的 Sharpe 比率)的觀察差距,除了階段二有明確證據支持「兩者真的沒有實質差異」以外,其餘全部落在現有樣本量檢定力不足以偵測的範圍內。第10週的檢定力分析反推,要用現有的資料頻率偵測到 0.2 的 Sharpe 差,需要約 104 年的樣本外資料——這是本篇報告對「為什麼難」最直接的量化。

# 研究問題與主旨

## 研究問題

規則型策略(ORB 開盤區間動能、VWAP 趨勢)在 QQQ 上是否可以透過機器學習方法改善?具體而言:(1) 波動率預測能否改善以波動率為基礎的部位管理策略?(2) 市場狀態(regime)能否事先判定,並用來篩選規則策略的交易日?(3) 用交易日當天開盤前後的資訊,能否預測一筆訊號值不值得進場?(4) 放棄人工設計特徵、直接用深度學習處理原始分鐘序列,能否得到更多資訊?

## 主旨

**機器學習能改善預測指標,但在扣除實際成本後,無法在現有樣本下顯著改善 QQQ 短期策略的績效。**

這句話裡三個限定詞都是刻意的:「能改善預測指標」——階段二、四、五都有模型在 QLIKE/AUC 這類純預測指標上贏過基準,不是全面沒有訊號。「扣除實際成本後」——策略層的差異顯著性檢定(block bootstrap)才是真正的門檻,純預測指標的優勢常常撐不到這一層。「現有樣本下」——檢定力分析(第10、14週)量化了這不是「還沒找到對的模型」,是現有樣本外(out-of-sample, OOS)樣本量在統計上本來就偵測不到這個量級的效果,跟模型好壞無關。

# 資料與方法論

## 資料

研究使用 QQQ 的分鐘與日線價量資料(2014年12月至2026年9月),以及 VIX/VXN 隱含波動率指數。所有原始資料下載自 Interactive Brokers,清理後存為 parquet 格式,並記錄填充率、異常值等資料品質指標(第1週)。策略層使用的兩個規則策略——ORB(開盤區間動能)與 VWAP(趨勢跟隨)——複現自 Zarattini 與 Aziz 的日內交易研究(ORB: Zarattini & Aziz, 2023;VWAP: Zarattini & Aziz, 2023,*Volume Weighted Average Price (VWAP): The Holy Grail for Day Trading Systems*)。

## 方法論紀律

本專題橫跨14週,每週遵循以下五項方法論原則,構成整份報告最重要的方法論貢獻:

**事先寫定設定**:每週的分析設定、成功標準寫進當週的 `config/weekNN_*.toml`,在看任何結果之前定案;結果不論好壞照實報告,不因結果不理想就放寬標準或悄悄多跑幾次換更好看的數字。第8週是這項紀律最直接的例子:原始三項成功標準字面上全部達成,但補做四項檢查後推翻了「達成」的字面結論(見「階段四:交易日篩選」一章)。

**巢狀 walk-forward 驗證**:每折訓練段內再切配適(fit)段與驗證(validation)段,測試段完全不參與配適或選門檻;驗證段選定的模型與門檻原封不動套用到測試段,不重新配適。這個設計避免了「用測試段的資訊挑選模型」這個常見的資料洩漏管道。

**截斷與篡改測試**:第五階段 CNN 使用的分鐘序列特徵,逐一測試截斷(confirm 特徵在決策時點之後被截斷不影響預測)與篡改(confirm 篡改決策時點之後的資料不會改變預測),確保沒有未來資訊洩漏到序列特徵裡。

**隨機基準與 block bootstrap 雙層檢定**:排序層檢定問「模型選中的交易日,跟隨機選同樣天數比有沒有差」;策略層檢定(block bootstrap,移動區塊拔靴法)問「篩選前後的績效差本身站不站得住腳」。這兩層經常給出不同答案,策略層通常比排序層嚴格得多——「階段四:交易日篩選」一章的證據階梯是這個方法論設計的具體展示。

**檢定力分析**:第10週引入,量化「現有樣本量本來就有沒有機會偵測到某個量級的效果」;第14週擴大到 AUC 差,並補算到階段二、三。這是唯一能回答「是模型不夠好,還是資料量不夠」這個問題的工具。

## 統計慣例說明

本報告策略層的年化 Sharpe 比率,統一採用**算術平均定義**(日報酬平均值除以標準差,再乘以 √252),跟 block bootstrap 顯著性檢定、最小可偵測差(MDE)使用的是同一個定義,因此報告中「觀察差」欄位會恰好等於兩個 Sharpe 相減。**這跟各週報告(第5、7、8、12週等)顯示的 Sharpe 數字不同**——那些週報告顯示的是**複利/幾何年化定義**(用複利計算的權益曲線反推年化報酬,再除以年化波動),這是全專案自第五週起用於呈現策略績效的慣例。兩種定義本來就分工:複利定義貼近實際權益曲線、給人報酬感覺;算術定義在區塊拔靴重抽樣數千次時計算成本低、統計性質更單純,從第五週起就一直是顯著性檢定內部使用的定義,只是從未被放進同一張表格直接比較過。第14週第一次把兩者放進同一份總表(`results_summary.json`)時處理了這個問題,並確認改用算術定義後,全部策略層比較的方向(誰高誰低)沒有任何一個翻轉,詳見下表。

# 階段二:波動率預測與部位管理

## 方法

比較四種已實現波動率(realized volatility)預測方法——隨機漫步、HAR(異質自迴歸)模型、HAR 加上 XGBoost 殘差修正、20日歷史波動率——並將預測結果轉換為波動目標(volatility-targeting)部位規模,評估策略層 Sharpe 比率。

## 主要結果

預測層:HAR+殘差XGB 對 HAR 的 QLIKE 損失函數差為 -0.0147,Diebold-Mariano 檢定 p = 0.00045(顯著改善)。

策略層:HAR+殘差XGB 對 HAR 的策略 Sharpe 差為 -0.0026(p = 0.9173),對 20 日歷史波動率的 Sharpe 差為 -0.0161(p = 0.8517)——**兩者都不顯著**。預測層準確度的改善,沒有轉化為策略層的顯著改善。

## 隨機基準:波動目標本身的價值

第14週補做的隨機基準檢定,回答了一個不同的問題。主比較問的是「哪個模型的波動預測比較好」(不顯著);這個隨機基準問的是「真實的波動資訊,對比打亂日期後的波動資訊,對這套部位規則有沒有差別」——把 HAR+殘差XGB 的預測值在日期間隨機打亂、重新接回同一套波動目標部位規則,重複 1000 次,得到觀察 Sharpe(1.1257)排在隨機打亂分布的第 96.9 百分位(p = 0.0310,單尾)。

兩者合起來一致支持階段二的結論:**波動目標部位規則本身有價值,但哪個模型提供波動預測,影響不大**。這是本專案第一次為「波動目標有價值」這個主張補上正式的統計證據——先前(第5週危機切片一節)只有「波動目標策略在危機期間最大回撤較淺」這種描述性證據,沒有正式檢定。

## 修正紀錄:20日歷史波動率的前視偏誤

在進入階段三之前的全面複查中,發現 20 日歷史波動率的部位權重計算納入了「當天自己」的收盤到收盤報酬,構成前視偏誤。修正前該變體的 Sharpe 為 1.4715,修正後為 1.1568;修正後,HAR、HAR+殘差XGB、20日歷史波動率三者的策略 Sharpe 統計上沒有顯著差異。此修正是在看任何階段三結果之前主動查出並修正的(詳見附錄 A 修正紀錄)。

## 穩健性

成本敏感度:主成本假設下的策略比較,額外用 3 倍交易成本重跑,結論(HAR+殘差XGB 與 HAR 無顯著差異)不變——用 3 倍成本涵蓋了原訂 2 倍加倍測試的範圍,較規劃更嚴格。逐年拆解:各年度 Sharpe 詳見第5週報告,未發現單一年份主導整體結論的情形。參數敏感度:波動目標水準與槓桿上限的 3×3 組合網格測試,結論方向一致。

# 階段三:市場狀態標籤

## 方法

用 HMM(隱馬可夫模型)與 KMeans 對開盤前市場特徵分類為 2-4 個狀態,評估狀態標籤能否事先判定、以及拿狀態篩選 ORB/VWAP 交易日能否提升策略績效。

## 附帶結果:論文複現

在建立狀態標籤之前,先複現 ORB 與 VWAP 兩個規則策略,對照原論文的取樣期間與部位規則:ORB 複現 Sharpe 1.012 對論文 1.13,VWAP 複現 Sharpe 2.339 對論文 2.1,同一量級,複現通過。VWAP 複現過程中,第一次嘗試誤用了 ORB 的部位規則(每筆風險 1% 權益、4 倍槓桿上限),得到明顯偏高的複現 Sharpe(3.26)與過深的最大回撤(−35.9%);查出原因後改為 VWAP 自己論文的規則(100% 權益、不加槓桿、股數每日開盤算死一次),才得到上表的複現數字(詳見附錄 A)。

VWAP 在真實交易成本下的 Sharpe 大約只有論文(近乎零成本假設)的一半——單位曝險 Sharpe 在論文取樣期間,主成本下為 1.261,換成論文近乎零成本假設下為 2.046,VWAP 平均每天反手約 16.6 次,對成本假設極度敏感。

## 狀態可事先判定嗎

用模型外驗證(predictive-type 狀態分組去解釋一個從未用來配適狀態標籤的真實已實現波動率,Newey-West HAC 標準誤,state 0 為對照組):HMM state 1 對 state 0 的已實現波動差 t = 9.93(p ≈ 0),state 2 對 state 0 的差 t = 12.20(p ≈ 0)。**狀態標籤本身站得住腳,不是純雜訊。**

## 拿狀態篩選交易日,能提升策略績效嗎

HMM 狀態篩選 ORB:篩選後 Sharpe 0.2390 對不篩選 0.3956(差 -0.1566,p = 0.5700);篩選 VWAP:0.9166 對 1.0191(差 -0.1026,p = 0.4407)。**兩者都不顯著,且篩選後都比不篩選差。** 18 個「狀態 vs 全樣本」比較裡,0 個在 p < 0.05 顯著。

第14週補做的逐年拆解確認了這個結論的另一面:沒有一個狀態連續 8 年都同向為正,最一致的狀態也只有 7/8 年為正,最不一致的只有 2/8 年為正——**狀態效果沒有年度一致性**,支持「0/18 顯著」是穩健結論,不是巧合。

## 穩健性

成本加倍(第14週補做):ORB、VWAP 兩策略在雙倍交易成本下,篩選仍然比不篩選差(ORB 差 -0.1314,VWAP 差 -0.1615),跟主成本下的方向完全一致。狀態數敏感度:k=4 對照 k=3 的主結果,結論方向不變。

# 階段四:交易日篩選

## 方法

用交易日開盤前後的 14 個特徵(隔夜跳空、已實現波動、第一根5分鐘K線的方向與形態等),訓練 logistic regression、隨機森林、XGBoost 等模型,篩選當天的 ORB 訊號值不值得進場。

## 主要結果與證據階梯

Logistic 篩選模型的 AUC 為 0.5965(中等)。篩選後 Sharpe 0.7254 對不篩選 0.5540(差 +0.1714),字面上看起來提升明顯,但 **block bootstrap 顯著性檢定 p = 0.4845,不顯著**。

第8週建立時,原始三項成功標準(篩選後夏普>不篩選、篩選後夏普>隨機篩選第95百分位、每年≥20筆交易)字面上全部達成;使用者要求補做四項檢查後推翻了這個字面結論——block bootstrap 不顯著、效果集中在兩個極端年份(2022 大幅為負、2026 大幅為正)部分抵銷、成本敏感度是唯一完全正面的結果。此事直接促成第9週把 block bootstrap p < 0.05 明訂為四項嚴格成功標準之一。五個模型(logistic、隨機森林、XGBoost 深度2/3、Huber 迴歸)**沒有一個四項標準全過**,樹模型還出現嚴重過擬合,詳見下表。

|---|---|---|---|
| logistic | 0.667 | 0.612 | 0.056 |
| 隨機森林 | 0.828 | 0.620 | 0.207 |
| XGBoost(深度2) | 0.901 | 0.591 | 0.310 |
| XGBoost(深度3,附錄) | 0.965 | 0.591 | 0.373 |

## 檢定力分析

第10週的檢定力分析回答了「現有樣本量本來就有機會偵測到這個量級的效果嗎」:5% 顯著、80% 檢定力下的最小可偵測 Sharpe 差為 0.6923,遠大於實際觀察到的 0.17-0.22。反推要用現有的資料頻率偵測到 0.2 的 Sharpe 差,需要約 104 年的 OOS 資料——這不是換模型或多等一兩年能解決的量級落差。

## 穩健性:ORB 停利倍數敏感度

第14週補做:ORB 的停利設定從論文預設的 10R,分別改成 5R 與 15R 重跑(沿用第8週以 10R 標籤訓練出的篩選決定,不重新訓練模型),檢驗的是同一批被選中的交易日,換算到不同停利定義下報酬,篩選是否仍然較好。5R 下篩選對不篩選差 +0.2403(p = 0.3065),15R 下差 +0.1462(p = 0.5440)——**篩選優於不篩選的方向在 5R、10R、15R 三個停利定義下都一致,三者都不顯著**,跟主結果「方向正但不顯著」的型態吻合,不是矛盾。

成本加倍、驗證窗網格、保留比例網格等第10週的其餘穩健性檢查,詳見附錄與第10週報告。

# 階段五:深度學習(CNN)

## 方法

放棄人工設計的開盤特徵,把開盤前後的分鐘級價量序列直接餵給一個小型 1D 卷積神經網路(1809 個參數),用 5 個固定種子訓練並平均機率,跟第8週手工特徵 logistic 模型比較。任務A:開盤前5根1分鐘K線,預測 ORB 淨報酬是否為正;任務B:開盤後 N=15、30 分鐘,預測到收盤的方向。CNN 架構、訓練流程、種子從第11週定案後凍結到第13週,不曾因結果不理想而調整。

## 主要結果

CNN 對手工特徵 logistic 的 AUC 差為 -0.0554(**block bootstrap p = 0.0008,顯著更差**)——CNN 不但沒有超出手工特徵的資訊,反而顯著更差。三項增量資訊檢查(CNN 分數與手工特徵的 Spearman 相關、CNN logit 對手工特徵的 OLS 迴歸 R²、CNN 分數與手工特徵堆疊的增量測試)一致確認 CNN 沒有超出手工特徵的資訊。策略層:CNN 篩選 Sharpe 0.2213 對不篩選 0.4211(差 -0.1997,p = 0.4700,不顯著)。

任務B(開盤後15、30分鐘序列預測剩餘時段方向)在 AUC 層與策略層都一致確認沒有可用訊號,兩個時間窗口的結論一致。

## 穩健性

第14週補做的逐年拆解:CNN 篩選在 8 年中只有 4/8 年優於不篩選——沒有一致優勢,呼應「沒有增量資訊」的主結論。成本加倍下,篩選仍比不篩選差(差 -0.1811),跟主成本下的方向一致。CNN 架構本身的參數敏感度未重新打開(架構凍結是本專案既有紀律,第14週指示下不重開這個決定),但兩個間接證據可以部分回答設計選擇是否穩健:任務B 的 N=15、N=30 兩個獨立時間窗給出一致結論,不是單一窗口的偶然;每折5個固定種子的測試 AUC 範圍(見第12週報告)顯示初始化變異的量級遠小於「CNN 比手工特徵差」這個結論的效果量。

## 診斷:2020年(第2折)

CNN 在第2折(2020年,COVID崩盤與反彈)的測試 AUC 降到 0.4483(低於隨機),是 8 折裡表現最差的一折。描述性分析確認 2020 年是樣本期間市況最極端的年份之一(年化波動、VIX、大幅波動天數都是數一數二)。這裡僅做描述,不修正任何已報告的合併或逐折數字。

# 綜合討論:為什麼難

四個階段的模式高度一致:預測層(QLIKE、AUC、外部驗證檢定)經常有統計上站得住腳的訊號或差異,但策略層的觀察差全部遠小於 5% 顯著、80% 檢定力下的最小可偵測差,如下圖與下表所示。

**但這不是同一種「測不到」**:階段二的最小可偵測差只有 0.0686——不同波動預測模型接同一套部位規則後,產生的部位序列高度相關,配對比較的變異數本身就小,檢定力足夠高。觀察差(-0.0026)遠低於這個小的門檻,是**有檢定力支持的「沒有實質差異」**,不是量不到,是真的量出來很小。階段三到五的最小可偵測差落在 0.69–0.79 這個大得多的量級——樣本量(交易日數)沒有本質改變,但效果本身混在整體策略報酬的雜訊裡,檢定力不足。這三個階段是**偵測不到**,不是**偵測到沒有差異**——如果背後真有一個中等大小的效果,現有樣本量本來就看不出來,不能倒過來說「證明沒有效果」。

第10週的反推把這個落差量化到具體年限:要用現有的資料頻率偵測到 0.2 的 Sharpe 差,需要約 104 年的 OOS 資料——這是全篇報告對「為什麼難」最直接的量化,不是換模型或多等一兩年能解決的量級落差。

四個階段疊加起來看,主旨的三個限定詞各自都有直接證據:「能改善預測指標」——階段二、四、五都有預測層的統計顯著改善或有效訊號;「扣除實際成本後」——策略層的 block bootstrap 檢定是所有模型共同卡住的地方;「現有樣本下」——兩次獨立的檢定力分析(第10週 Sharpe、第14週 AUC)從不同指標得到一致結論。

# 限制與未來工作

## 方法論限制

樣本量是貫穿全專案的根本限制,不是任何單一階段的執行問題——這一點被兩次獨立的檢定力分析從不同角度確認。2022 年的方向性弱點(階段四的做空訊號排序顛倒)目前只由三個共用同一組特徵、訓練窗高度重疊的模型「發現」,只能算一個假說,不是三次獨立驗證。任何看完全部結果後才挑選的探索性組合(如階段四的兩特徵 logistic 模型),都打上探索性折扣,不能當作下一步的起點直接採用。

## 未來工作

1. 調查2022年做空訊號排序顛倒的具體機制(階段四附帶發現,已描述但未深入歸因)。
2. 更長記憶的深度學習架構(LSTM、Transformer)列為未來工作,但前提是有明顯更長的分鐘級歷史資料可用才成立——現有樣本量下,CNN(1809個參數)的過擬合差距已經不小,參數更多的架構需要更多資料才能負責任地訓練,不是更少。
3. 若未來樣本量顯著增加(更長歷史或更高頻率的獨立訊號),值得重新評估檢定力是否改善到可行範圍——但依現有的反推,這不是短期內可行的方向。
